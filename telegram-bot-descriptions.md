## Настройка в BotFather

1. Откройте [@BotFather](https://t.me/BotFather)
2. Отправьте `/mybots` и выберите вашего бота
3. Используйте следующие команды:

**Edit Bot:**
- `/setabouttext` — Short description (120 символов)
- `/setdescription` — Description (512 символов)
- `/setcommands` — Список команд

**Bot Settings:**
- ✅ **Inline Mode** — отключено (не используется)
- ✅ **Group Privacy** — включено (только обращения к боту)
- ✅ **Allow Groups** — по желанию

**Дополнительно:**
- Установите аватар бота (желательно с иконкой AI/мозга)
- Добавьте теги: ai, assistant, productivity, journal, tasks

## Технические детали

**Архитектура:**
- TypeScript + Bun
- Effect Framework для оркестрации
- PostgreSQL + Drizzle ORM
- OpenAI GPT-4o-mini
- Multi-agent AI система

**Безопасность:**
- Шифрование учетных данных (AES-256-GCM)
- Защита API-ключей интеграций
- Аутентификация для мини-приложения

**Масштабируемость:**
- Кэширование агентов (1 час)
- Кэширование интеграций (15 минут)
- Batch-операции для задач
- Оптимизированные запросы к БД
