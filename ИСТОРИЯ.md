# История диалогов в Telegram боте

## Реализованная функциональность

### Автоматическое отслеживание истории
- ✅ Каждое сообщение пользователя сохраняется в историю
- ✅ Каждый ответ бота также сохраняется в историю  
- ✅ История передается в AI агент для контекстных ответов
- ✅ Отдельная история для каждого чата (пользователя)
- ✅ Ограничение размера истории (20 сообщений на чат)

### Команды управления историей
- `/start` - запуск бота
- `/history` - показать количество сообщений в истории
- `/clear` - очистить историю диалога

### Структура истории
```typescript
interface ConversationMessage {
  role: 'user' | 'assistant';
  content: string;
  timestamp: number;
}
```

## Как работает

1. **Пользователь отправляет сообщение** → сохраняется в историю как `user`
2. **Бот получает историю диалога** → передает в AI агент
3. **AI агент отвечает с учетом контекста** → ответ сохраняется как `assistant`
4. **Следующее сообщение** → процесс повторяется с накопленной историей

## Преимущества

- 🧠 **Контекстные ответы**: AI помнит предыдущие сообщения
- 🔒 **Изолированность чатов**: история не смешивается между пользователями  
- ⚡ **Быстродействие**: история хранится в памяти
- 🎯 **Ограничение ресурсов**: максимум 20 сообщений на чат

## Пример использования

```
Пользователь: "Создай встречу завтра в 15:00"
Бот: "Встреча создана на завтра в 15:00"

Пользователь: "А можешь ее перенести на час позже?"  
Бот: "Конечно! Переношу встречу с 15:00 на 16:00"
    ↑ Бот помнит о встрече из предыдущего сообщения
```
